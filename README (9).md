## Мета

Навчитися створювати Flutter-застосунок, працювати з введенням, списками та станом екрана, відокремлювати обчислення від інтерфейсу й перевіряти код інструментами Flutter.

## Реалізовані можливості

- Поле числового введення з підтримкою знака та десяткового роздільника.
- Два випадні списки: °C, °F і K.
- Кнопка «Конвертувати» та блок результату.
- Пояснення для порожнього поля, тексту, нескінченності, переповнення та температури нижче абсолютного нуля.
- Приймаються крапка та кома, крайні пробіли ігноруються.
- Результат округлено до двох знаків; значення з модулем від 1 млрд показуються у науковому записі.
- Після редагування числа або одиниць попередній результат очищається, щоб не показувати застарілу відповідь.

Клавіатура є підказкою для пристрою, а не перевіркою даних: текст можна вставити з буфера, тому введення додатково перевіряється у класі обчислень. Дані не надсилаються в мережу й не зберігаються після закриття застосунку.

## Формули

Базова шкала обчислень — Цельсій:

- C = (F − 32) × 5 / 9;
- C = K − 273,15;
- F = C × 9 / 5 + 32;
- K = C + 273,15.

Мінімальні допустимі значення: −273,15 °C, −459,67 °F, 0 K. У коді множення й ділення переставлені там, де це допомагає уникнути проміжного переповнення. Незначну похибку від'ємного результату біля 0 K нормалізовано до нуля. Невалідне введення повертає `FormatException`, яку екран перехоплює і показує як текст, а не аварійне завершення.

| Вхід | Перетворення | Очікуваний результат |
|---|---|---|
| 0 | °C → °F | 32,00 °F |
| 36,6 | °C → °F | 97,88 °F |
| −40 | °C → °F | −40,00 °F |
| 273,15 | K → °C | 0,00 °C |
| 32 | °F → K | 273,15 K |
| −274 | °C → K | Повідомлення про абсолютний нуль |
| abc або порожній рядок | Будь-які | Пояснення правильного введення |

## Запуск

Перевірена версія інструментів: Flutter 3.35.5, Dart 3.9.2. Установіть Flutter SDK та Android Studio з Android SDK, Command-line Tools і емулятором. Додайте Flutter до PATH.

```bash
flutter doctor --android-licenses
flutter doctor -v
flutter pub get
flutter analyze
flutter test
flutter devices
flutter run -d DEVICE_ID
```

`DEVICE_ID` замініть ідентифікатором із `flutter devices`. Для емулятора спочатку запустіть віртуальний пристрій у Device Manager. Для телефона активуйте USB debugging і підтвердьте доступ комп'ютера. На цільовій Android-платформі проблеми `flutter doctor` потрібно усунути перед здачею.

Додаткова вебперевірка:

```bash
flutter run -d chrome
flutter build web
```

Вебзбірка не замінює необхідного запуску на емуляторі. API, сервер чи ключі доступу не потрібні.

## Hot Reload / Hot Restart

Це план власного експерименту з очікуваною поведінкою за документацією Flutter. Фактичний запуск Hot Reload на Android у середовищі підготовки не виконувався.

1. Запустити debug-версію. Ввести 36,6, обрати °C → °F та отримати 97,88 °F.
2. У `converter_screen.dart` змінити текст заголовка на «Мій конвертер».
3. Виконати Hot Reload (`r` у терміналі). Новий текст має з'явитися, а введене число, одиниці та результат — зберегтися.
4. Виконати Hot Restart (`R`). Застосунок створить стан заново: поле стане порожнім, одиниці повернуться до °C → °F, результат — до заглушки.

| Дія | Очікувана поведінка | Фактичне спостереження студента |
|---|---|---|
| Зміна тексту + Hot Reload | Оновлено напис, збережено стан | Заповнити |
| Hot Restart | Скинуто поле, одиниці й результат | Заповнити |

Hot Reload перебудовує віджети, зберігаючи State; `main()` й `initState()` не виконуються повторно. Hot Restart запускає застосунок заново. Зміна нативного коду може вимагати повного перезапуску.

| Труднощі | Рішення |
